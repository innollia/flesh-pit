## Current design translations

| Digging-game concept | flesh-pit equivalent |
| --- | --- |
| inventory capacity | stomach capacity |
| return pressure | stomach fullness + regrowing tunnel |
| base | clean white restroom |
| empty inventory | vomit |
| upgrade economy | mutation |
| tunnel persistence | flesh regrows and narrows old routes |
| ore/collectible | cancer/tumor codex specimens, role still limited |
| navigation aid | compass + canary |
| biome/depth tier | anatomical region / tissue system |

## Current flesh-specific mechanics

### Regeneration
Excavated flesh grows back and gradually narrows the route home.

### Nerves
Yellow, protruding, wriggling structures; disturbing them can deform nearby tissue.

### Cancer / tumors
Collectible/codex content. Additional gameplay benefit is undecided.

### Blood vessels
Removed from the current core design.

## Mechanical research targets

Need stronger references for:
- satisfying elastic tearing / chewing
- regrowing or self-closing tunnels
- return-path pressure without a hard timer
- tool progression that preserves the identity of eating
- navigation in self-authored 3D tunnels
- small death-recovery systems
- canary-like environmental warning companions

## World / depth research targets

- brainstorm distinct depth zones from giant-organism fiction and anatomy references
- keep all resulting worldbuilding original
- each depth band must change mechanics, not only visuals

## Presentation research targets

- clean safe-room contrast against gross organic space
- mutation shown through hands, sound, shake, and stomach UI
- restroom content that changes across progression
- readable yellow nerve language against red tissue
- cancer/tumor codex presentation
