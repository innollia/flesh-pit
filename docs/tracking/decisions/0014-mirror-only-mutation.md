# 변이는 화장실 거울 앞에서만 산다

2026-11-14. 변이를 어디서 사느냐는 물음에 사용자가 "거울"이라고 답했다. 전에는 Tab 화면이 열리는 곳이면 어디서나(살 속, 쉼터) 샀다.

## 결정

Tab 화면은 지금처럼 어디서나 열린다. 사는 것은 화장실 안에서 거울을 가까이 들여다볼 때만 된다(`Main.at_mirror`). 조건은 셋이다.

- 몸이 화장실 안에 있다.
- 거울장 문이 닫혀 있다(문이 열려 있으면 들여다볼 거울이 없다).
- 눈에서 거울 점(`mirror_point`)까지 1.6 m 이내이고, 시선이 그 점에서 35도 이내다.

판정은 거울 위치만 본다. 변기와 환풍구가 어디 있든 상관없다. 화면을 여는 순간 한 번 묻는다(열려 있는 동안 몸과 시야가 멈춰 있다).

쉼터에서 사던 사람은 화장실까지 돌아와야 한다. 쉼터 깊이는 4.5 / 13.5 / 22.5 m(화장실 중심에서 직선, `fp_world_features.gd` `REST_DEPTH`)이고 웅크림 1.5 m/s로 3.0 / 9.0 / 15.0초, 걷기 3.0 m/s로 1.5 / 4.5 / 7.5초다(계산). 문이 한쪽이라 실제 길은 더 길다(추정).

## 신호

| 때 | 보이는 것 |
|---|---|
| 처음 살 수 있게 됐을 때(산 변이가 없고, 털이나 혹이 값을 치를 수 있다) 화장실에서 거울이 화면에 보인다 | 거울 위에 Tab 키캡이 맥동한다(첫 레버의 고리와 같은 방식). 변이를 하나라도 가지면 다시 나오지 않는다. 저장하지 않는다 |
| 거울 앞에서 살 것이 있다 | 조준 고리의 글자가 Tab 키캡이 된다(거울장 문을 여는 F와 손은 그대로다). 이때 맥동 키캡은 꺼진다(한 입력은 한 곳에만) |
| 거울 앞에서 Tab | 전과 같다. 살 수 있는 줄은 값만큼 팔털이 깜빡이고, 혹은 박동하고, 사면 털이 떨어지고 몸이 바로 바뀐다 |
| 거울 앞이 아닌 곳에서 Tab | 목록·부위 반짝임·유령(살 수 있는 모습)은 그대로 보인다. 팔털은 깜빡이지 않고 혹은 박동하지 않는다 |
| 거울 앞이 아닌 곳에서 사기를 누른다 | 유령이 0.15초 꺼졌다 켜진다. 털은 그대로이고 붉은 거절도 거절 소리도 없다(`FPMirror.not_here`만 난다. 소리는 붙이지 않았다) |

## 확인

`game/tests/run_mirror_buy_discard_hold_tests.gd`가 본다: 거울 앞 판정의 경계(30도·40도, 1 m·1.9 m, 등 돌림, 거울장 문), 방 안에서 등 돌린 자리·살 속·쉼터에서 화면은 열리되 사기가 아무것도 바꾸지 않는 것, 혹도 같다는 것, 거울 앞에서는 전과 같이 사지는 것, Tab 키캡 두 가지.

이 시험이 찾은 버그 하나를 같이 고쳤다. Tab 화면을 두 번째로 열면 인형의 혹이 새로 지어지면서 이름이 바뀌어(`TumorBump0` → 자동 이름) 혹을 찾지 못했고, 그래서 박동도 누르기도 되지 않았다. 지울 조각의 이름을 먼저 비켜 준다(`FPMirrorBody._reset_shapes`).

## 남은 것

- "여기서는 못 산다"가 유령 깜빡임만으로 읽히는지, 거울로 가야 한다는 것을 Tab 키캡이 알려 주는지는 사람이 봐야 한다.
- 쉼터에서 변이를 못 사게 된 만큼 쉼터의 쓸모가 줄었다. 쉼터 설계는 따로 다시 볼 수 있다(사용자: 갈아엎어도 된다).
