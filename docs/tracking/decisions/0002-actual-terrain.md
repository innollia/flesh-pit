# 실제 살점으로 내부 표시

표면 방향을 고쳐도 카메라가 완전히 찬 셀 안에 있으면 볼 면이 없고, 단계 게시 중에는 오래된 표면과 새 굴착이 다르다.

지형에 한정한 재질과 실제 고체 셀·게시된 표면의 증거, 미게시 실제 밀도의 임시 면으로 수리한다. 공유 면과 충돌은 같은 지형을 표현한다.

검은 배경이나 화면 덮개는 외부 누출을 숨길 뿐 조준과 이동 공간을 일치시키지 못한다. 플레이어 순간이동은 기존 이동과 자세를 바꾼다. 전체 공통 재질의 양면화는 손·피부·가구에 영향을 준다. 이 대안들은 사용자가 요구한 실제 살점 수리가 아니다.

실제 임시 면과 내부 셀 면의 비용이 생긴다. 범위를 제한하고 실제 청크를 근거로 종료해야 한다. 외부 껍질을 정상 돌파한 경우까지 내부 면으로 가리는 것은 허용되지 않는다.
