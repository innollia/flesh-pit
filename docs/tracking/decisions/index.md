# 결정 목록

| 기록 | 결정과 결과 |
|---|---|
| 0000-rolling-human-sphere | 무대는 구르는 인간 구체, 엔딩은 도시로 떨어지기 |
| 0001-continuous-regeneration | 지연 없이 계속 자라되 기본률을 낮춘다 |
| 0002-actual-terrain | 실제 고체와 미게시 밀도에서 면을 만들어 내부 누출을 막는다 |
| 0003-publication-and-restore | 일반 굴착은 단계 게시, 저장 복원은 첫 화면 전에 한 번 전체 준비한다 |
| 0004-tumor-specific-mutations | 종양 변이는 먹은 종양의 종류로 정해진다. 무작위 추첨을 쓰지 않는다 |
| 0005-spray-economy | 3통 상한은 거의 걸리지 않으므로 그대로 두고, 통당 뿌리기를 6회에서 8회로 올린다(통당 횟수는 0006이 6회로 되돌림) |
| 0006-rest-spray-loot | 쉼터마다 그 깊이의 스프레이 한 통을 한 번만 줍고, 통당 뿌리기는 6회로 되돌린다 |
| 0007-clean-room-playtest | 플레이어 에이전트는 화면만 보고, 평가자가 텔레메트리와 함께 증거로 판정한다 |
| 0008-knife-gate-farther | 핵은 막까지 맨손으로 파고, 칼은 원정 한 번 값(8개), 맨손 거절은 손과 소리로 알린다 |
| 0009-first-expedition-return | 첫 레버 정산 전 밖 토하기는 헛구역질(위장이 상한일 때는 0013이 예외로 둠), 위장을 버리는 밖 토하기는 0.8초 누르기(2026-11-14), V 표시는 변기·쉼터에서만, 허리에 차고 손에 드는 나침반 |
| 0010-biomes-per-shell | 껍질마다 바이옴 여러 개(새 다섯 개), 바이옴마다 조직·빈 곳·구조물·빛·소리, 배치는 고정 |
| 0011-spec-archive | 1차 기획서를 `docs/archive/spec-v1/`로 보관하고 지금 기준은 코드와 `docs/design/`이다 |
| 0012-economy-recalculation | 살 단위 2, 압축 재생 1.0(핵 1칸 굴 111초), 칼의 조직별 가중, 과식 걸음 75%, 수축 예고 1.5초, 저장 version 6보다 앞선 슬롯은 새 게임. 손잡이 금지는 잘못 기록된 것 |
| 0013-full-stomach-vomit-before-first-settle | 첫 정산 전이라도 위장이 상한(160)에 닿으면 밖 토하기가 위장을 비운다(보상 없음). 굴이 닫혀 갇히는 것을 재현하고 0009를 고침 |
| 0014-mirror-only-mutation | 변이는 화장실 거울 앞에서만 산다(1.6 m·35도, 거울장 문 닫힘). Tab은 어디서나 열리고 밖에서는 보기만 한다 |
| 0015-level-dig-stall | 수평 굴 정체의 원인은 턱이다. 웅크리기+먹기가 오르기를 막지 않게 하고, 막힌 몸이 조준선 아래 살을 잡는다. 문턱은 남음 |
