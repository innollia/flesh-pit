# 살 단위 2, 압축 재생 1.0, 칼의 조직별 가중, 무거운 과식 걸음, 옛 저장은 새 게임

2026-11-14. 핵심 재미 감사(`docs/design/core-fun.md`)가 남긴 질문 가운데 사용자가 답한 것을 값으로 옮겼다. 사용자 말은 지휘 세션을 거쳐 전달됐다.

## 사용자 답

- "씹는 시간·뜯는 범위·살 단위·위장 용량을 건드리지 말라"는 금지는 잘못 기록된 것이다. 그때 요청은 실험 삼아 재생 속도만 조절해 보라는 것이었다. 지시서대로 이 값들을 바꿔도 된다.
- 핵의 좁은 굴이 지표면보다 먼저 닫히는 것은 닫힘을 가르치려는 의도다. 그 정도는 다시 본다.
- 기존 저장과의 호환은 지키지 않아도 된다. 저장 변환 코드는 넣지 않고, 저장 버전만 올려 옛 저장은 새 게임으로 시작하게 한다.
- 칼은 조직마다 가중을 달리한다. 과식하면 걸음이 무거워진다.
- 쉼터 설계는 갈아엎어도 된다(이 결정에서는 손대지 않았다).
- 가려움 안내 문구는 임시라 무시한다(기준으로 삼지 않는다).

## 결정

1. 살 단위: 온전한 한 칸은 2단위다(`FDKStomachConfig.flesh_per_cell`, 전에는 4). 위장 100은 50칸, 과식 끝 160은 80칸이다. 씹는 시간 0.6초, 위장 용량 100, 과식 폭 60, 과식 배수 3은 그대로다.
2. 털과 그 둘레 값을 같은 비율로 맞췄다: 색 털 한 가닥은 가중 살 25, 공통 털은 75(전에는 50 / 150). 변이 값은 공통 24, 핵 12, 맨틀 20, 지표면 30가닥(전에는 12 / 6 / 10 / 15). 팔 털 `SHAGGY_AT` 80, 몸 털 `BODY_FULL` 240, 환풍구의 털 말 `HAIRS_REMARK` 40, 위장 덩어리 `KICK_UNITS` 2. 원정 한 번이 주는 가닥 수가 같고 변이 하나에 드는 원정 수도 같다(핵 3, 맨틀·지표면 2.5).
3. 압축 살의 재생 배율은 1.0이다(`FDKTissueRules.REGEN`, 전에는 1.5). 이웃 배율(`CROWD_GAIN`), 기본률, 깊이 배율, 다른 조직은 그대로다. 핵에서 넓은 곳 111초 → 167초, 1칸 굴 74초 → 111초, 막다른 곳 56초 → 83초. 맨틀 수축 123.5초, 지표면 신경 122.5초는 그대로다. 지표면 ÷ 핵 1칸 굴의 기울기는 1.65에서 1.10이 됐다. 안쪽이 먼저 닫힌다는 뜻은 남기고 정도만 줄였다.
4. 살 단위와 압축 재생은 한 묶음이다. 살 단위만 2로 하면 원정이 두 배로 길어져 74초짜리 굴이 가득 차기 훨씬 전에 닫힌다. 목표는 "가득 찰 때까지는 돌아올 수 있고 더 먹으면 길이 닫힌다"이고, 압축 1.0은 한 입 1.5초(헛동작 포함)인 사람에게 맞춘 값이다.
5. 칼은 조직마다 가중이 다르다(`FDKTissueRules.KNIFE_SPEED`): 압축 1.0, 옛 지방 1.0, 천 1.1, 신경 1.2, 털 1.3, 수축 1.4, 연골 1.6, 막 1.6. 씹는 시간은 0.6초 × 경도 ÷ 가중이라 칼 든 손으로 주 조직은 전부 0.6초, 막 0.75초다. 전에는 모든 조직을 1.6으로 나눠 칼이 한 입의 박자를 지웠다(핵 0.375초). 큰 톱은 그대로다.
6. 과식 걸음: 위장이 용량을 넘으면 걷는 속도가 줄어 과식 끝에서 75%다(`FPProgression.GORGE_WALK_MIN`). 다른 감속과 곱하지 않는다(압사 시계가 돌면 끼임 배율만, 비집기와는 더 느린 쪽만). 머리 흔들림 최대 1.5배, 발소리 0.85배 높이·+3 dB. 오르기와 시야각은 그대로다.
7. 수축 예고 소리는 조임 1.5초 전이다(`CONTRACT_WARN`, 전에는 1.3). 과식 끝의 걸음으로 위험 반경을 빠져나가는 데 반응 반 초를 더해 1.48초가 들기 때문이다. 걷기 변이가 없을 때 기준이며 M14와 T7을 함께 가지면 과식 없이도 1.52초가 필요하다.
8. 저장: `Main.SAVE_VERSION` 6. 그보다 앞선 슬롯은 변환하지 않고 읽지 않는다. 파일은 그대로 두고 시작 화면은 새 게임만 내놓으며, 새 게임이 저장될 때 덮인다. 옛 슬롯을 읽던 변환 코드는 지우지 않았지만 더는 지나가지 않는다.
9. business-rules.md의 금지 문장을 지우고 "맨손 기본 살 한 입 0.6초는 근거 없이 바꾸지 않는다"로 바꿨다.

## 확인한 것

- 계산기(`tools/economy/reward_scale.py`, `docs/design/economy.md`): 원정 44.5~118초 → 89.3~205초(목표 180~300초, 닫힌 굴을 다시 뜯는 시간은 빠져 있다). 귀환 여유(B08) 가득(100)일 때 1.80 / 2.70 / 1.08 / 2.00 / 1.81 / 1.99로 동적 상한을 뺀 다섯이 대역(1.5~4) 안이고, 과식 끝(160)에서는 0.89 / 1.33 / 0.53 / 0.99 / 0.89 / 0.98로 전부 낮다. 과식 끝의 1 아래는 의도된 값이다. 회차 1.6~2.1시간(목표 4~6시간보다 짧다).
- 실제 지형(`game/tests/run_economy_r2_tests.gd`, 전부 압축 조직인 합성 지형, 깊이 배율 1.0): 닫힘 시간 166.7 / 166.7 / 111.2 / 83.4 / 66.7초(고체 이웃 0~4개). 2줄 굴 34걸음을 한 입 2.7초로 파면 184초에 103단위, 돌아설 때 34걸음 가운데 12걸음이 닫혀 있고(입구의 위·아래 모서리 줄 0.99, 가운데 줄 0.78), 13걸음을 다시 뜯어 34.9단위를 더 먹고 137.9단위로 돌아온다. 거절 없음. 한 입 0.9초면 61초에 다 파고 닫힌 걸음이 없다(입구 줄 0.25).

## 받아들인 것

- 칼을 사면 과식이 전보다 위험해진다. 칼 든 손의 과식 끝 압사 여유가 핵 1.78 → 1.11, 맨틀 1.27 → 1.11, 지표면 1.48 → 1.11로 맨손 값과 같아진다(기준 1.5).
- 살 2와 과식 걸음과 칼 가중이 겹쳐 맨틀·지표면 칼의 과식 끝 귀환 여유가 0.99 / 0.98이다.
- 가득 찬 뒤 한 입 더부터 길이 닫히는 것이 글자 그대로 맞는 것은 한 입 1.5초인 사람뿐이다. 더 빠르면 과식 구간 뒤쪽에서야 닫히고, 더 느리면 가득 차기 전에 닫혀 다시 뜯어 돌아온다. 사람 속도는 아직 재지 않았다.
- 첫 정산 전에 위장이 160에 닿은 채 굴이 닫히면 나올 길이 없었다. 재현했고 결정 0013이 막았다.

## 고르지 않은 것

- 살 단위 2에 압축 1.5를 두는 안: 2줄 굴에서 핵 1칸 굴의 귀환 여유가 1.04로, 가득 차기 전에 닫힌다.
- 압축 0.9 이하: 가득 찬 뒤에도 길이 닫히지 않아 과식이 도박이 되지 않는다.
- 저장을 변환하는 안(옛 털을 두 배로): 사용자가 호환을 지키지 않아도 된다고 했다.
- 큰 톱에도 가중을 넣는 안: 한 번에 6칸을 뜯는 도구라 조직 가중으로는 박자를 못 고친다. 열린 질문으로 남겼다(`docs/tracking/findings.md`).
- 신경 가중 1.0: 지표면 칼의 과식 끝 압사 여유가 0.93이 되어 탈출할 수 없다.
