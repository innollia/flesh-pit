# 기획서와 현재 구현의 차이 — 2026-10-06

## 대조 기준과 범위

타이밍 복구본을 Desktop에 적용한 직후의 코드와 `docs/spec/00~08`, `10-first-ten-minutes.md`, `content/vent-lines.md`, `tone-and-manner.md`, 이후 사용자 요청을 대조했다. 기획서보다 나중에 승인된 변경은 버그로 분류하지 않았다. 이번에는 차이를 목록화했으며 아래 항목을 임의로 수정하지 않았다. 커밋·푸시도 하지 않았다.

코드의 실제 호출과 신호 소비자를 확인했다. 일부 차이는 격리된 Main 논리 확인으로 보강했다(`.dryforge/evidence/eating-timing/design-difference-probe.json`). 직접 변이를 설정하고 한 번 논리를 진행한 관찰이므로 실제 전체 플레이 재현과 구분한다. 목록에 없는 항목까지 모두 기획대로 완성됐다는 뜻은 아니다. 특히 이미지 A와의 화장실 구도·모션의 시각적 품질·4~6시간 전체 밸런스는 이번 코드 대조만으로 판정하지 않는다.

## 4. 이번 목록으로 미구현이라고 판단하지 않은 것

먹을 때 털 성장, 믹서기60% 섭취·1.5초 돌리기+1.5초 마시기·신경 충전, 큰 톱 최대6셀, 스프레이 영구 용해, 도감 크레용 그림, 종양7종 변이 선택, 껍질별2/4/6개 쉼터, 도구 가격·해금, 문 다시 닫기, 여러 키로 변기에서 일어서기는 코드에 존재한다. 일반 손의 피·거울 소지 상태·B/Tab의 승인 기준도 이번 타이밍 수리에서 바꾸지 않았다.

`fp_progression.gd`에는 과거 `BLENDER_PACKING=0.7`, `dig_multiplier()` 같은 흔적이 남아 있지만 현재 사용 경로는 `FPTissueTools.BLEND_RATIO=0.6`과 조직별 계산이다. 죽은 상수만 보고 현재 믹서기 효과가70%라고 보고하지 않았다.

이번 적용 후 해당 원본 게임 소스를 별도 복사해 저장·설정을 격리하고 새 게시 검사364항목과 B/문 보존265항목, 자연 프레임 연속3회 실제 화면을 재확인했다. 각 명령 자체 종료0이다. 앞선 전체1,749항목/GUI6개 통과와 적용 후629항목/자연 프레임 재확인은 구분한다. D01~D11을 전부 정상 플레이로 재현하거나 수정한 것으로 취급하지 않는다.
