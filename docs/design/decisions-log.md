# 사용자 결정 모음

사용자가 대화에서 직접 내린 결정을 날짜순으로 모은다. 큰 결정의 근거는 `docs/tracking/decisions/`에 있다. 이 문서는 그보다 작은 판정까지 사용자 말과 함께 남긴다.

- 인용은 사용자 말 원문이다. 따옴표가 없는 칸은 요약이거나 다른 세션을 거쳐 전달된 것이다.
- 2026-11-03~04는 대화 추출본에서, 2026-11-07은 본 세션의 전달에서 옮겼다.
- 상태: 반영(코드에 있음), 유지(바꾸지 않기로 함), 진행 중, 대체(뒤 결정이 바꿈).
