# 구성과 연결

게임 실행 장면은 Main이다. Main이 화장실·시작과 설정·입력·진행·저장·화면 표현을 연결하고, Flesh Dig Kit의 지형·먹기·위장·손·플레이어·방벽을 생성한다. 키트는 재사용 계산과 노드를 제공하며 Main을 역으로 참조하지 않는다.

소리 연결은 Main 아래에서 키트와 게임 신호를 구독한다. 소리 디렉터는 목록에 등록된 스트림을 재생하고 주변음·씹기 루프를 조절한다. 게임 상태 변경은 소리 모듈의 책임이 아니다. 외부 서버나 계정 서비스는 플레이에 필요하지 않다.

대표 흐름은 입력 → Main의 거리·차폐·도구 검사 → Chewer의 잡기와 진행 → Terrain의 공유 밀도 제거 → 제거된 표면·충돌 갱신 → 위장 또는 들고 있는 살·진행 갱신이다. 손과 소리는 이 흐름의 신호를 받아 표현한다. 표시용 면을 추가한 경우에도 실제 지형 상태가 그 면의 근거다.

지형은 청크별 상태를 보관하고 공유 경계의 밀도를 같이 수정한다. 연결된 청크의 갱신은 같은 스냅샷을 사용해 게시한다. 아직 게시되지 않은 굴착은 실제 밀도에서 만든 임시 표면으로 드러낸다. 생성기의 원래 밀도와 플레이 중 수정된 밀도는 별개다.

자동저장은 Main이 지형·플레이어·진행·소지를 하나의 로컬 슬롯으로 묶는다. 설정과 키 배치는 별도 JSON이다. 복원은 저장 상태를 적용하고 실제 지형 표시와 충돌을 준비한 후 입력과 렌더링을 이어간다.
