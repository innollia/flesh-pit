# 게임 행동

살을 잡아 유지하면 시간이 누적되어 한 셀을 뜯는다. 도달 거리 안의 뜯을 수 있는 살만 유효하다. 가구에 가려진 살, 빈 공간과 범위 밖은 먹지 못한다. 입력을 놓거나 시선·거리 조건을 잃으면 중단한다. 진행은 실제 제거와 동시에 위장 또는 들고 있는 살로 반영된다. 막은 기존 칼 조건을 따르고 용해된 살은 먹을 수 없다.

살은 원래 밀도까지 계속 재생한다. 기본률은 초당 0.003이며 조직·깊이·이웃 밀집도·스프레이 주변 배율을 적용한다. 배율 1에서 밀도 0이 고체 기준 0.5에 도달하는 기본 시간은 약167초다. 재생 대기 시간은 없으며 수축은 별도 위험 동작이다. 스프레이로 영구 용해한 부분은 자라지 않는다. 몸·방벽·화장실·쉼터 주변의 보호는 재생에서 존중된다.

통로가 서서히 좁아지는 긴장과 귀환 판단을 유지한다. 위장 과식은 기존 속도·섭취 제한을 따른다. 느린 재생을 흉내 내기 위해 씹는 시간·뜯는 범위·살 단위·위장 용량을 바꾸지 않는다. 방벽은 결손 밀도와 깊이에 따른 압력, 이완·손상·파손을 유지한다. 기본 재생을 낮춘 뒤에도 기존 유효 압력 0.28을 유지하도록 압력 계수를 함께 보정한다.

먹고 파기 → 위장 증가 → 화장실 또는 쉼터 귀환 → 토하고 정산 → 이빨과 털로 도구·변이 구매 → 바깥 탐색의 흐름이다. 손 도구와 벨트 교환은 현재 좌·우 손 액션을 따른다. 휠·점프·빠른 숫자 도구 키를 과거 기획만으로 다시 붙이지 않는다.

현재 회차는 한 슬롯으로 자동저장한다. 이어하기는 파낸 공간·영구 용해·소지·진행을 유지하며 새 재생 속도를 적용한다. 엔딩 이후 시작 화면으로 돌아간다. 실제 바깥 껍질 돌파에서 외부를 보는 것은 내부 살점 면의 누출과 구별한다.
