# 기능 보존 복구 — 2026-10-02

사용자 지시: 시계 보듯 팔을 드는 Tab 모션과 크기를 복원하고, 인형은 카메라에 맞춰 각도만 바꾼다. 피부는 기존 몸색을 기준으로 한다. 문 앞 조명 감소는 유지한다. 화장실 크기를 복원한다. 휠 조작을 제거한다. 그 밖의 확인된 기능 훼손을 복구한다.

## 복구 내용

- Tab 발 위치에 적용하던 카메라 높이·거리 제한을 제거했다. 기존 `DOLL_SCALE = 0.16`을 유지하며 인형의 발을 움직이는 팔 위에 고정한다. 회전만 카메라 축을 따른다.
- 일반 팔과 변이 팔 모두 시계 모션을 받는다. 실제로 보이는 팔을 인형의 기준으로 사용한다. Tab에서 변이를 적용해 팔 리그가 바뀌어도 인형과 표시 레이어가 새 팔을 따라간다.
- Tab에서 클릭하거나 이동 키를 눌러도 시계 모션이 취소되지 않는다. Tab을 닫을 때 내려놓는다. Tab에서는 기존 긴 털 팔 메시를 다시 표시하고, 일반 플레이에서는 좌우 동일한 팔을 유지한다.
- 큰 인형과 변이 목록이 겹치지 않도록 목록을 인형 옆에 배치한다. 기존 부위 선택, 후보 선택, 구매, 털 비용, 거부 표시, 후보 기억과 미리보기를 유지한다.
- 기존 몸의 정점 색과 기존 피부 텍스처의 혼합·조명 계산을 피부 기준으로 복원했다. 얼굴 이미지의 색을 몸에 적용하지 않는다. 이미지에서는 이목구비 명암만 취한다. 손의 젖음 광택과 PS1 정점 스냅을 복구했다.
- 턱 변이는 이미지가 붙은 머리의 하부 정점을 실제로 변형한다. 눈 변이는 이미지 눈의 크기·깊이·위치를 변경한다. 기본 얼굴은 이미지이며 변이 눈에만 별도의 이미지 면이 표시된다. 얼굴 미리보기에도 이목구비와 턱 변형이 남는다.
- 피부의 불필요한 투명 렌더링을 제거했다. 뒷머리가 앞 얼굴을 덮어 이목구비가 사라지는 렌더링 문제도 수정했다. 투명 렌더링은 미리보기와 변이 눈에만 사용한다.
- 물탱크를 바라보고 F로 들고 있는 치아를 반환하는 경로를 복구했다. 표시와 실행에 같은 거리·각도·차폐 판정을 적용한다.
- 오른손 칼을 들고 왼손이 비어 있으면 가위를 다시 표시한다. 가위는 거울에도 반영한다. 살점 운반 시 왼손이 비어 있으면 소유한 믹서기를 그 손에 들며, 왼손 도구 사용으로 작동한다.
- 카나리아의 임의로 줄였던 크기도 원래 1.4 배로 복원했다. 팬티 안에 들어가고 천이 부푸는 요청된 표현은 유지한다.
- 방 폭을 기존 4.5 m로 복원했다. 사진 기준 가구 구조·정사각형 타일은 유지했다. 벽 쪽 변기와 시작 위치도 넓어진 방에 맞춘다. NPC의 변경했던 이동 대화 거리도 원래 값으로 복원했다.
- 방 조명의 그림자와 거울 표면 줄무늬를 복구했다. 문 앞 조명은 승인된 0.85/0.25 값을 유지한다. 피부색을 틀어지게 하던 거울의 전체 청색 색조는 재적용하지 않는다.
- 신경 등장에 붙였던 특정 Z 방향 조건을 제거했다. 초기에는 숨겨지고, 굴착 이후에는 방향에 관계없이 생성될 수 있다.
- 저장 버전 5: 좁은 방을 저장한 구버전에도 넓은 방 공간을 적용한다. 기존 밀도와 새 방 밀도의 최솟값을 사용해 이미 판 구멍을 채우지 않는다. 저장 위치가 실제 살점 속일 때만 이동시키며 정상적인 위치는 보존한다. 이미 덮어써진 저장 지형을 과거 상태로 재구성하는 기능은 아니다.
- 게임 도구 선택과 Tab 후보 선택의 휠 입력을 제거했다. Z/X와 Tab의 위/아래 선택은 유지한다.
- 스프레이의 두 종류 보관 위치를 허리 앞쪽의 선택 가능한 위치로 조정했다. 좁은 시선 판정과 허리 회전 제한을 유지한 상태에서 두 종류 모두 선택·교환되는지 검사했다.
