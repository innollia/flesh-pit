# 작업 계획

기준 기획서: `docs/spec/`. 진행 기록: `game/STATUS.md`.

- 담당: **프론트**는 화면에 보이는 것(손·몸 메시와 애니메이션, 화장실·물체 생김새, UI, 캡처 판정)이다. **백엔드**는 로직, 데이터, 테스트, 빌드다.
- 코드 상태
  - **있음**: 관련 코드가 있다. 새 기준과는 아직 대조하지 않았다.
  - **충돌**: 코드가 새 기준과 다르다.
  - **없음**: 코드가 없다.
- 완료 조건을 테스트나 캡처로 확인할 수 있어야 완료다.
- **지금 있는 그림 에셋(모델, 텍스처, `assets/`, `game/main/art/`의 생김새)은 전부 불합격이다(2026-09-29 형님 판정).** 코드 상태가 "있음"이어도 생김새는 `docs/asset-list.md` 기준으로 새로 만든다. 로직과 연결 코드만 재사용한다.
