# 그림·모델 목록

기준: `docs/spec/`, `docs/tone-and-manner.md`. 옛 목록(2D UI 위주, 깊이 띠 8개)은 `docs/archive/asset-list-v1.md`에 있다.
마지막 수정: 2026-09-29

## 0. 읽는 법

이 게임은 텍스처를 입힌 PS1 로우폴리 3D다. 화면 UI는 거의 없고 몸이 HUD다. 그래서 이 목록의 대부분은 3D 모델과 그 텍스처다.

| 열 | 뜻 |
|---|---|
| ID | 고정 ID. 번호를 다시 매기지 않고, 안 쓰게 되면 "폐기"로 둔다 |
| 이름 | 짧은 이름 |
| 생김새 | 무엇이 어떻게 보이는지. 상태가 여럿이면 모두 적는다 |
| 규격 | 모델은 삼각형 수 상한, 텍스처는 px. `128`은 128×128 |
| 종류 | `모델`, `리그`(뼈대+동작), `텍스처`, `셰이더`, `효과`, `UI`, `그림` |
| 우선 | `M1`~`M3`는 `plan/work-plan.md`의 마일스톤. `확장`은 보류 |
| 쓰임 | 왜 필요한지, 기획서의 어디인지 |
| 현재 | 지금 코드에서 이 물건을 그리는 파일, 또는 `없음`. **2026-09-29 형님 판정: 지금 있는 그림·모델·텍스처는 전부 불합격이다.** 이 열은 "어디에 연결돼 있나"만 알려줄 뿐이고, 모든 항목을 새로 만든다 |

### 공통 규칙
- 텍스처는 64~256 px, 최근접 필터, 밉맵 없음. 살은 사진 같은 표면.
- 모델은 삼각형 수 상한을 지킨다. 실루엣은 뭉툭해도 된다.
- 그림에 글자를 넣지 않는다. 예외: 도감 크레용 그림(글씨처럼 보이는 낙서만), 로고.
- 화장실은 깨끗하고 하얗게 둔다. 얼룩, 살, 썩음을 넣지 않는다.
- 신경의 노랑이 가장 채도 높은 색이다.
- 변이 생김새는 1인칭(손, 팔, 내려다본 몸)과 거울 속 전신 두 곳에서 모두 맞아야 한다.
