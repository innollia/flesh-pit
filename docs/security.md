# 로컬 데이터 경계

게임은 로컬 실행이며 외부 인증·서버·네트워크 상태 공유를 사용하지 않는다. 플레이에 API 키를 추가할 필요가 없다.

사용자의 실제 회차 저장은 검사용 초기화 대상이 아니다. Main을 생성하는 검사에서는 ready 이전에 별도 경로를 주고 ready가 경로를 변경하는 경우 실행 전 다시 지정한다. 옛 저장 검사에는 검증된 과거 파일의 복사본을 사용한다. 설정·키 배치도 사용자 파일을 덮어쓰는 검증을 하지 않는다.

저장 실패는 성공으로 처리하지 않는다. 새 상태는 임시 파일에 기록한 뒤 기록 오류를 확인하고 슬롯 파일로 이름을 바꾼다. 복사본 검사는 실제 슬롯 복구 성공을 의미하지 않는다. 손상된 파일을 임의로 새 게임 데이터로 덮어 정상처럼 만들지 않는다.

작업 공간의 미커밋 팔·Tab·피부 변경과 사용자 조사 파일은 타인의 데이터다. 수정 범위가 아니라는 이유로 삭제·초기화·통째로 스테이징하지 않는다. 비밀 값이 필요한 개발 도구 설정은 git에서 제외된 env 파일에 둔다.
