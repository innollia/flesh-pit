# 00. 개요

용어: `CONTEXT.md`. 무대·엔딩 결정 기록: `docs/adr/0001-rolling-human-sphere-and-fall-out-ending.md`.

## 한 줄

구체 한가운데 화장실에서 시작해, 다시 자라는 살을 먹으며 바깥으로 파고 나가 도시 길바닥으로 떨어지는 1인칭 게임.

## 전제

- 무대는 수천만 명의 인간이 뭉친 거대한 구체다. 화장실을 속 빈 껍질 3겹(핵, 맨틀, 지표면)이 감싼다.
- 플레이어의 정체는 끝까지 밝히지 않는다.
- 살은 그냥 살이다. 먹는 것에 도덕적 무게를 두지 않는다. 목소리나 기억 조각 같은 연출도 없다.
- 사람의 흔적은 드물게만 둔다. 살에 박힌 검은 점(머리카락) 정도이고, 옷 뭉치 바이옴은 확장 때 넣는다.
- 구르기는 드리프트로만 표현한다. 중력 회전 같은 별도 기능은 없다.
- 원작 세계만 쓴다. Mystery Flesh Pit 같은 참고작의 이름, 설정, 생물, 지도는 가져오지 않는다.

## 핵심 루프

1. 화장실 문을 열고 살을 뜯어 먹으며 판다.
2. 위장이 찬다. 과식하면 더 먹을 수 있지만 느려진다.
3. 재생으로 좁아진 통로를 지나 화장실이나 쉼터로 돌아온다.
4. 변기에 토하고 물을 내려 정산한다. 물탱크에 이빨이 쌓이고, 팔에 털이 자란다.
5. 환풍구에서 이빨로 도구를 사고, 거울에서 털로 변이를 산다.
6. 다시 나가 더 바깥쪽으로 판다.

- 핵심 긴장은 재생이다. 위장은 돌아갈 때를 알려주는 시계다.
- 원정 1번은 3~5분, 엔딩까지는 4~6시간이 목표다.

## 엔딩

- 가장 바깥 껍질을 뚫으면 가사 없는 평화로운 허밍과 함께 도시 길바닥으로 떨어진다.
- 밝은 낮이고, 사람들은 평소처럼 지나가며 굴러가는 구체를 신경 쓰지 않는다.
- 카메라가 물러나며 구체가 굴러가는 모습을 보여주고, 크레딧이 나온다. 새 회차는 없다.
- 엔딩 노래의 선율은 살 속에서 미리 희미하게 들린다. 바깥 껍질일수록 커진다.
- 종양 도감을 다 채우면 엔딩 노래에 목소리가 한 겹 더해진다.

## 범위

작은 인디 게임이다.
- 지킨다: 먹고 파기, 재생 압박, 위장 시계, 화장실 쉼, 눈에 보이는 변이, 껍질 돌파.
- 하지 않는다: 생존 제작, 큰 전투, 기지 건설, 공원 경영, 긴 이야기.
