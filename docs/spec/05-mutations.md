# 05. 변이

## 1. 규칙

- 변이는 초능력이 아니라 몸의 변화다. 생김새와 파라미터가 함께 바뀐다.
- 변이를 먹었다는 건 소리, 발걸음 흔들림, 1인칭 손, 위장 UI로 드러난다. 숫자보다 먼저 몸으로 느껴져야 한다.
- Tab 변이 화면(팔뚝 위 인형)에서 털로 산다(`03-restroom.md` 8장). 선행 조건은 없다.
- 가지(공통, 압축, 수축, 신경, 조합)는 어떤 털로 사는지만 정한다. 가지와 부위는 대응하지 않는다.
- 변이마다 부위가 정해져 있다. 부위는 왼손, 오른손, 팔, 배, 얼굴, 다리 등이다.
- 새 동작이나 새 모션을 추가하는 변이는 피한다. 기존 동작의 파라미터를 바꾸는 쪽을 택한다.
- 효과는 `CONTEXT.md`와 `01-body-eating.md`의 파라미터 이름으로만 적는다.
- ★ 표시는 위장 UI의 생김새도 바꾼다.

구성 목표: 공통 6, 압축 7, 수축 7, 신경 7, 조합 3, 총 30개.

## 4. 종양 변이

- 종양 포인트로 얻는다. 무엇이든 크게 바뀐다.
- 종양을 먹으면 배에 작은 혹이 솟는다. 변이 화면에서 그 혹을 누르면 혹이 터지듯 자라나 무작위 종양 변이 하나가 된다. 언제 변이할지는 플레이어가 고른다.
- 종양을 먹는 효과음이 따로 있다.
- 확정 목록 (7개)

| ID | 이름 | 생김새 | 효과 |
|---|---|---|---|
| T1 | 반향정위(박쥐) | 혀를 딸깍 참 | 윤곽만 보이고 다른 것은 보이지 않는다. 대신 윤곽이 아주 뚜렷해 살벽 상황(얇은 곳, 재생 중인 곳, 수축 직전인 곳, 신경, 종양)을 전부 안다 |
| T2 | 세 번째 팔 | 가슴에서 팔 하나가 더 돋음 | 셋째 팔이 믹서기를 늘 든다. 왼손이 비어 먹기와 두 손 도구를 같이 쓴다 |
| T3 | 손바닥 입 | 오른손바닥에 입 | 잡자마자 먹는다. base_chew_time ×0.4. 오른손으로 살 더미를 들 수 없다 |
| T4 | 부푼 몸통 | 몸통이 풍선처럼 부풂 | capacity ×2. body_radius ×1.3 |
| T5 | 어안 | 눈이 머리 양옆으로 옮겨감 | 시야각 90도 → 200도(물고기 눈처럼 휨) |
| T6 | 세로 턱 | 턱이 세로로 갈라짐 | 막을 입으로 뜯는다. 막 경도 2.0 → 1.0. 환풍구 존재가 이 얼굴을 무서워하는 대사가 생긴다 |
| T7 | 부채 갈비 | 갈비뼈가 부채처럼 벌어짐 | 멈춰 서 있는 동안 반경 1.5 m 안 재생이 멈춘다. 이동 속도 ×0.8 |

- 같은 종양 변이는 두 번 붙지 않는다. 7개를 다 받으면 더 먹어도 혹이 생기지 않는다.
