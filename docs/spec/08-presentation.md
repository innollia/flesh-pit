# 08. 표현과 조작

## 1. 글자

- 화면에 글자를 거의 쓰지 않는다. 손, 몸, 물리 신호, 소리로 알려준다.
- 상시 HUD 글자와 숫자는 거의 없다. 몸이 HUD다(손, 위장 덩어리, 목, 허리띠, 팔의 털).
- 예외: 위장 %와 막대(가득 차면 토하기 키 표시, 사용자 요청), 도감, 환풍구 존재의 자막, 오프닝 조작 안내.
- 친절함은 설명 글이 아니라 눈에 잘 띄는 신호로 준다. 예: 변이 화면의 빛나는 부위, 깜빡이는 비용 털, 상호작용 가능한 물체.

## 2. 조작

- 1인칭이다.
- 마우스+키보드와 게임패드를 모두 지원한다.
- 모든 화면이 마우스만으로도, 키보드만으로도 조작돼야 한다(변이 화면, 환풍구 거래, 물탱크 포함).

현재 코드의 키 배치(`game/main/data/keybinds.json`, `fp_input_modes.gd`):

| 동작 | 마우스+키보드 | 키보드만 | 게임패드 |
|---|---|---|---|
| 보기 | 마우스 | 방향키 | 오른쪽 스틱 |
| 이동 | WASD | WASD | 왼쪽 스틱 |
| 왼손 사용(먹기는 누르고 있기) | 좌클릭 또는 E | E | LT |
| 오른손 사용 | 우클릭 또는 R | R | RT |
| 상호작용 | F | F | X |
| 토하기 | V | V | Y |
| 살 더미 들기/내려놓기 | Q | Q | B |
| 방벽 놓기 | G | G | 십자키 위 |
| 종양 먹기 | T | T | 십자키 오른쪽 |
| 웅크리기 | Ctrl | Ctrl | 왼쪽 스틱 누르기 |
| 살 속 위로 파기(4.5 m/s) | 스페이스 | 스페이스 | A |
| 살 속 아래로 파기(2.5 m/s) | Ctrl+좌클릭 | Ctrl+E | 왼쪽 스틱 누르기+LT |
| 변이 화면 열기/닫기 | Tab | Tab | LB |
| 이전/다음 도구 | Z / X | Z / X | 뒤로 / RB |

- 손 버튼은 그 손에 든 물건을 사용하거나 벨트 물건과 교환한다. 스프레이·섞기·먹이 같은 전용 버튼과 별도 먹기/줍기 버튼은 없다.
- 일반 점프는 없다. 스페이스는 살 속에서만 위로 판다.
- 마우스 휠 도구 선택은 없다. 도구는 Z/X와 Tab 화면의 키보드/마우스 선택으로 고른다.
- 오프닝에서는 W를 누를 때까지 앉아 있고, W·ASD·마우스 안내가 차례로 사라진다.
- 왼손 먹기(좌클릭)를 누르고 있으면 살이 계속 뜯긴다. 뜯는 동안 처음 겨눈 칸을 유지한다.

## 3. 소리

- 가깝고 젖은 몸 소리를 쓴다. 찢기, 씹기, 삼키기, 꾸르륵, 늘어나는 소리.
- 몸은 늘 들린다. 낮은 박동 같은 압력, 먼 소화음, 조직이 움직이거나 재생할 때 삐걱임.
- 변이는 숫자보다 먼저 플레이어 자신의 소리를 바꾼다(무거운 발걸음, 달라진 씹기).
- 화장실: 형광등 웅웅, 물, 타일 울림. 자기 숨소리가 들릴 만큼 조용하다.
- 파는 동안 음악은 없고 낮은 드론만 있다. 예외는 엔딩 노래의 희미한 선율이다.
- 종양을 먹는 효과음이 따로 있다.
- 소리 결정은 현재 추천안을 기본으로 한다. 예를 들어 발소리 변주 아래 작은 잡음층, 배경음 좌우 맥놀이, amb_pulse의 2 Hz 박동은 유지한다.
- 현재 소리 목록: `game/audio/SOUND_LIST.md`

### 살 속의 빛 (2026-10-19)

문을 나서 살 속으로 들어가기 시작할 때 화면이 하얗게 날아가지 않는다. 눈 램프 하나나 문 조명 하나만으로는 문제가 없었고, 둘이 더해질 때 날아갔다.
- 눈 램프는 방을 나서는 순간 켜지지 않는다. 눈이 어둠에 익는 2.5초 동안 30%에서 천천히 올라온다. 열린 문의 빛이 닿는 1.8 m 안에서는 눈이 익지 않아 램프가 낮게 머문다.
- 벽이 눈앞에 바짝 있으면 램프가 그만큼 약해진다. 아주 가까운 벽도 1.2 m 떨어진 벽처럼 보인다. 몸을 비집어 줄일수록 주변이 다 가까우므로 램프도 절반까지 약해진다. 옆·위·아래 벽은 0.4 m 안으로 붙었을 때만 셈한다.
- 문 조명(승인된 밝기 0.85)은 방에서 볼 때 그대로다. 문 바로 밖에서 그 빛줄기 안에 서 있으면 30%까지 약해졌다가, 문에서 3 m 멀어질수록 원래대로 돌아온다.
