# 08. 표현과 조작

## 1. 글자

- 화면에 글자를 거의 쓰지 않는다. 손, 몸, 물리 신호, 소리로 알려준다.
- 상시 HUD 글자와 숫자는 없다. 몸이 HUD다(손, 위장 덩어리, 목, 허리띠, 팔의 털).
- 예외: 도감, 환풍구 존재의 자막.
- 친절함은 설명 글이 아니라 눈에 잘 띄는 신호로 준다. 예: 변이 화면의 빛나는 부위, 깜빡이는 비용 털, 상호작용 가능한 물체.

## 2. 조작

- 1인칭이다.
- 마우스+키보드와 게임패드를 모두 지원한다.
- 모든 화면이 마우스만으로도, 키보드만으로도 조작돼야 한다(변이 화면, 환풍구 거래, 물탱크 포함).

현재 코드의 키에 추가 키를 더한 배치:

| 동작 | 마우스+키보드 | 키보드만 | 게임패드 |
|---|---|---|---|
| 보기 | 마우스 | 방향키 | 오른쪽 스틱 |
| 이동 | WASD | WASD | 왼쪽 스틱 |
| 먹기(누르고 있기) | 좌클릭 | 엔터 | RT |
| 상호작용, 줍기 | 우클릭 또는 F | F | A |
| 토하기 | V | V | B |
| 살 더미 들기/내려놓기 | Q | Q | X |
| 스프레이 | R | R | LB |
| 방벽 놓기 | B | B | RB |
| 웅크리기 | Ctrl | Ctrl | 왼쪽 스틱 누르기 |
| 점프 | 스페이스 | 스페이스 | Y |
| 변이 화면 열기/닫기 | Tab | Tab | LB |
| 다음 도구 | X 또는 휠 | X | - |

- 먹기(좌클릭)를 누르고 있으면 살이 계속 뜯긴다. 뜯는 동안 처음 겨눈 칸을 유지한다.

## 3. 소리

- 가깝고 젖은 몸 소리를 쓴다. 찢기, 씹기, 삼키기, 꾸르륵, 늘어나는 소리.
- 몸은 늘 들린다. 낮은 박동 같은 압력, 먼 소화음, 조직이 움직이거나 재생할 때 삐걱임.
- 변이는 숫자보다 먼저 플레이어 자신의 소리를 바꾼다(무거운 발걸음, 달라진 씹기).
- 화장실: 형광등 웅웅, 물, 타일 울림. 자기 숨소리가 들릴 만큼 조용하다.
- 파는 동안 음악은 없고 낮은 드론만 있다. 예외는 엔딩 노래의 희미한 선율이다.
- 종양을 먹는 효과음이 따로 있다.
- 소리 결정은 현재 추천안을 기본으로 한다. 예를 들어 발소리 변주 아래 작은 잡음층, 배경음 좌우 맥놀이, amb_pulse의 2 Hz 박동은 유지한다.
- 현재 소리 목록: `game/audio/SOUND_LIST.md`
