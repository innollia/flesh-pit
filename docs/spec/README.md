# 기획서는 보관됐다

1차 기획서 11장은 `docs/archive/spec-v1/`로 옮겼다(2026-11-07, 결정 0011). 파일 이름은 그대로다. 지금 기준은 코드와 `docs/design/`이다.

코드 주석이 `docs/spec/05-mutations.md`처럼 가리키면 같은 이름을 `docs/archive/spec-v1/`에서 찾는다. 그 글은 처음 의도를 보여 주는 기록이고, 코드나 새 문서와 다르면 코드와 새 문서가 맞다. 보관본은 고치지 않는다.

| 옛 장 | 지금 볼 곳 |
|---|---|
| 00 개요, 10 첫 10분 | `docs/design/overview.md` |
| 01 몸·먹기, 02 세계·조직, 05 변이, 06 도구, 07 위험·길 찾기 | 코드, `docs/business-rules.md`, `docs/tracking/decisions/` |
| 03 화장실 | `docs/design/vent-npc.md`(환풍구), 코드(`restroom.gd`, `toilet_settlement.gd`) |
| 04 경제, 09 보상 척도 | `docs/design/economy.md`(수치와 감사 표). 척도의 방법은 보관본 09 |

새 내용을 이 폴더에 쓰지 않는다.
