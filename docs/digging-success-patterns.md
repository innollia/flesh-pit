# Digging Success Patterns

This document summarizes the strongest recurring patterns across commercially or critically successful digging-focused games.

See detailed sources under `docs/references/`.

## The key pattern

Digging success is rarely about simulation depth.

The recurring structure is:

**obvious physical action → capacity/time/risk pressure → return → visibly stronger capability → new promise below**

The best games then add **one strong identity hook**.

## Pattern 1: The verb must be instantly legible

Successful examples:
- shovel the dirt
- drill the block
- vacuum the trash
- machine-gun the rock

The player understands the fantasy before understanding any economy.

### flesh-pit
- grab/tear/eat the flesh

If the first interaction needs a tutorial panel, simplify it.

## Pattern 2: Return pressure creates rhythm

Return triggers:
- full inventory
- battery
- enemy wave
- carrying weight
- resource banking

The important property is not punishment.
It is a repeated **decision boundary**.

### flesh-pit
- stomach fullness

The stomach should make the player greedy:
"one more bite before I go back."

## Pattern 3: Upgrades must be felt, not merely read

The strongest mining upgrades:
- increase destruction radius dramatically
- change movement
- automate hauling
- replace tools
- create explosions/synergies
- open new material

### flesh-pit
Major mutations should change:
- animation
- sound
- chunk size
- safe/unsafe targets
- route possibilities

## Pattern 4: Digging should author the map

A dug hole is:
- progress
- history
- return route
- navigation puzzle

This is one of the genre's cheapest ways to create player ownership.

### flesh-pit
Do not overwrite all tunnels too aggressively with regeneration.
Biological reaction should modify player-authored space, not erase its meaning.

## Pattern 5: Depth needs promises

Good digging games continually imply:
- better ore
- new biome
- relic
- boss/cave
- mystery
- stronger tool target

The player does not need a narrative reason to descend.
They need evidence that deeper space contains **new play**.

### flesh-pit
Foreshadow:
- new tissue
- cavity
- giant structure
- embedded infrastructure
- visible uncuttable anatomy
- unfamiliar pulse/sound

## Pattern 6: One twist is enough

Strong cases do not necessarily stack genres endlessly.

They often take mining and add one anchor:
- defense timer
- co-op
- platforming
- custom drill build
- ridiculous 3D hole premise

### flesh-pit
Our anchor is already unusually coherent:
**eat terrain + stomach inventory + toilet reset + mutation progression**

Do not dilute it with combat, crafting, survival meters and NPC systems unless a prototype proves a specific need.

## Pattern 7: Simple mechanics can still produce deep decisions

Dome Keeper is the clearest example:
- mining is simple
- timer creates many route/resource/carry decisions

### flesh-pit
Complexity should come from interactions among:
- remaining stomach
- distance to restroom
- tissue type
- vessel risk
- nerve risk
- intact growth reward

Not from extra buttons.

## Pattern 8: Players will ignore intended cleverness

SteamWorld Dig's original route-planning vision failed because people simply dug downward and trapped themselves.

### flesh-pit
Design for:
- straight-down eater
- greedy eater
- player who ignores vessels
- player who forgets route home

Then allow skilled play to outperform that baseline.

## Most important prototype question

Not:
"Is the lore interesting?"

Not:
"Does the flesh look gross enough?"

Test:

> **After returning to the toilet once, does the player immediately want to go down for one more stomachful?**

If yes, the genre loop is alive.
