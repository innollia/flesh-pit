# 게임 연결

Main은 키트 노드를 조합하고 화장실·진행·도구 액션·메뉴·팔과 거울·저장을 연결한다. 지형 청크의 재사용 계산과 공통 셰이더는 이 모듈의 소유가 아니다. 소리 파일을 통해 진행을 바꾸지 않는다.

조준 결과의 collider/position 계약을 유지하고 내부·임시 면도 실제 도달 거리와 가구 차폐를 적용한다. 잡기 기준은 실제 접점이며 손이 닿지 않는 다음 셀까지 진행을 이어가지 않는다. 스프레이·칼·톱도 공유 조준 소비자로 검사한다.

_world_density 캐시는 생성기 원래 밀도만 보관한다. 쉼터 레이아웃은 고정이고(`FPWorldFeatures.REST_LAYOUT`, 결정 0016) 실제 chunk 밀도·재생·섭취 상태를 넣지 않는다. 디스크 복원은 실제 표시·충돌을 한 번 준비하며 정상 굴착 루프에 전체 remesh를 추가하지 않는다.

Tab은 어디서나 열리지만 사는 것은 `Main.at_mirror()`일 때만이다(결정 0014). 변기·쉼터 밖 토하기는 `discard_hold_step`이 0.8초를 채워야 위장을 버린다. 쉼터의 V는 빈 양동이에만 토하고 그 이빨은 양동이에 남는다(`rest_teeth`). 양동이는 자기 위장에서 집어 간 이빨만 도로 받는다(`rest_bucket_room`). 이 자리 셈을 거치지 않고 `rest_teeth`를 올리는 길을 만들지 않는다. 화장실 밖에서 주머니 없이 이빨을 지닌 오른손은 묶인다(`Main.palm_blocked`, `FPInteractions.HOLD_TEETH`). 이 판정을 손 행동마다 따로 다시 쓰지 않고 `palm_blocked()`와 `FPProgression.palm_teeth_blocks`를 읽는다. 팔·Tab·거울·피부를 지형 수리와 섞어 변경하지 않는다. 현재 승인된 B의 오른팔 퇴장과 왼팔 상승, 원래 몸색, Tab0.20과 카메라 정렬을 실제 입력 검사로 확인한다. ready 이전과 이후의 저장 경로가 격리되어야 사용자 슬롯을 보호한다.

실제 입력 검사는 정상 process·physics·렌더링 보정을 그대로 사용한다. 추가 guard 콜백, 수동 손 진행만으로 Main의 정상 동작을 주장하지 않는다. 검증할 변화는 제거 밀도·섭취·게시된 구멍·이동 공간과 입력 해제다.

시체의 모습은 `art/fp_corpse_art.gd`의 `dress`가 짓는다(결정 0017). 살색 캡슐의 메시·색과 말뚝은 그대로 두고 그 아래에 털 매트·줄기·망울만 갈아 끼운다. 줄기 수는 시체에 남은 털 수에서만 나온다. 구조물을 감싼 막(결정 0018)은 생성기 `scripts/fp_biomes.gd`의 조직과 밀도일 뿐이다. 막 띠 안에 빈 곳이나 다른 조직을 다시 넣으면 찢지 않고 들어가는 길이 생긴다.
