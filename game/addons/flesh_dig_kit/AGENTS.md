# Flesh Dig Kit

재사용 지형·먹기·위장·손·플레이어·방벽·도구·변이·소리를 제공한다. Main·화장실·게임 진행 파일을 import하지 않는다. 세계 원래 밀도·조직·제약은 호출자가 주는 샘플러로 받는다.

청크 면은 표시와 충돌에서 같은 삼각형 방향을 쓴다. 공유 모서리의 변경과 원본 스냅샷을 이웃이 같이 읽는다. 지터의 공유 좌표만 같다고 안전하지 않으므로 면 교차와 대각선 유효성도 검사한다.

동결된 연결 그룹의 게시와 실제 밀도에서 만든 임시 면을 구분한다. 연속 재생이 현재 배치를 초기화하면 안 된다. 완료 표시는 소스 epoch와 실제 게시된 상태를 기준으로 한다. 완전 고체 내부 면은 실제 여덟 모서리 또는 게시된 표면 증거를 요구하며 임의 가짜 collider를 만들지 않는다.

Chewer의 잡기·진행·뜯기·놓기 신호는 손 mesh를 읽지 않는다. 실제 제거가 위장 증가와 같은 시점에 일어나야 한다. 막·용해 조건은 게임의 도구 연결과 함께 검증한다.

지형 수정 검사는 여섯 축·사선·음수 경계·작은 청크·예산1·연속 재생·미게시 영역 확장·실제 내부 렌더링을 포함한다. 재생 수치는 조직·깊이·이웃·스프레이 최종 배율과 보호·용해를 같이 확인한다.
