# flesh-pit

Small indie game concept built around a simple digging/progression loop inside a gigantic living organism.

## Core loop

**dig flesh → extract valuable material → sell/process it → upgrade tools → reach deeper tissue**

The project deliberately targets the compact, immediately readable progression loop seen in recent digging games rather than a large survival-horror or park-management game.

## Current differentiation hypothesis

The following pieces already exist separately:

- simple dig / sell / upgrade / dig-deeper games
- horror games where the player physically digs through flesh
- games about exploring gigantic organisms or biomechanical spaces

The combination below is the current project premise:

> A short, replayable mining/upgrading game where the mine itself is a gigantic living organism and biological layers replace conventional ore/depth tiers.

This is being treated as the working concept unless later research produces a close prior example.
