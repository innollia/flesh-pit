# Public-domain source image pool

Raw reference material for building game assets. These are source images, not final in-game assets.

## Packs

- `victorian-narrative-wood-engraving/`: scene/world material, centered on *The Illustrated London News* (1860–1861): interiors, architecture, streets, transport, crowds, landscape, objects.
- `victorian-encyclopaedic-engraving/natural-history/`: natural-history plates from *Brehms Tierleben*.
- `victorian-encyclopaedic-engraving/industrial/`: machinery and technical illustrations from *Appletons' Cyclopaedia of Applied Mechanics* (1880).

Images are fetched from Wikimedia Commons at a maximum width of 1600 px to keep the repository reasonably small. Exact source filenames, source pages, dates, and rights notes are preserved in `manifest.json`.

## Rights

The ILN selections are marked public domain / no known restrictions on Wikimedia Commons. The Brehm selections are public-domain scans of public-domain originals. The Appletons source was published in 1880; the selected Commons files are marked "no known copyright restrictions", and the work is public domain in the United States by publication date.

Keep `manifest.json` with the assets so provenance is not lost.
