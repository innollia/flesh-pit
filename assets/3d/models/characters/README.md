# No assets yet

This folder is for geometry and rigs, and it is intentionally empty.

A procedural PNG cannot stand in for a rigged hand or a hard surface
prop, so the generator does not fake one. See
[docs/asset-scope-2d-3d.md](../../../docs/asset-scope-2d-3d.md) for the
list of what belongs here and who owns it.

Loose shape references for the modeller live in
[2d/art/concept/3d-reference](../../../2d/art/concept/3d-reference/).
